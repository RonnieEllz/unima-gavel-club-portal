# Admin Guide

This guide explains how to operate the system as an administrator.

## 1. Access the admin area

1. Log in with an admin account.
2. Open the Admin Dashboard.
3. Use the navigation menu to access each admin section.

## 2. Member management

### Approve a member

1. Open Members.
2. Locate the pending member.
3. Change status to active.
4. Save the record.

### Review member records

Use the Members section to:

- review details
- check membership status
- manage active and pending accounts

## 3. Meeting management

### Create a meeting

1. Open Meetings.
2. Add the meeting details.
3. Save the meeting.

### Open check-in

1. Select the meeting.
2. Click Open Check-in.
3. Members can now check in.

### Close check-in

1. Select the meeting.
2. Click Close Check-in.
3. Attendance is finalized.

## 4. Attendance tracking

Use the Attendance section to:

- review attendance records
- correct mistakes when needed
- export data for reports

## 5. Content management

### Publish updates

1. Open Updates.
2. Create a new update.
3. Add title and content.
4. Publish.

### Publish stories

1. Open Stories.
2. Create a new story.
3. Add cover image if needed.
4. Publish.

### Upload gallery images

1. Open Gallery.
2. Upload the image.
3. Use it for stories or promotions.

## 6. Reports and exports

Use Reports to:

- review attendance trends
- monitor member activity
- export club records for operational use

## 7. Administrator permissions

Use the Administrators section to assign roles.

Roles include:

- Super Admin
- Administrator
- Operations Administrator
- Content Administrator

Only assign roles to trusted people.

## 8. Best practice checklist

- Approve new members promptly
- Open meeting check-in at the start of the session
- Close check-in when the meeting ends
- Keep updates current
- Maintain accurate attendance records
- Review reports regularly

## 9. Troubleshooting

### Member cannot log in

- Confirm the member is active
- Confirm the login details are correct
- Check whether the account is pending

### Member cannot check in

- Verify the meeting is open
- Confirm the member account is approved
- Check that the meeting has not been closed

### Admin cannot access a section

- Confirm the assigned admin role includes access to that section
- Review the role assignment in Administrators

## 10. Summary

The admin workflow is simple:

1. approve members
2. create meetings
3. open attendance
4. close attendance after the session
5. manage stories and updates
6. review reports and exports

This keeps the club organized and ensures a consistent member experience.
